# System

A lightweight network authentication and connection management utility.

---

## ✨ Features

- **Automated Portal Detection**: Fast probe and automated authentication.
- **Dynamic Rotation**: Multi-profile management with randomized rotation.
- **AES-256 Encryption**: Secure AES-256-GCM configuration synchronization.
- **Diagnostic Engine**: DHCP self-healing and telemetry collection.
- **System Tray Service**: Silent background monitoring and notifications.
- **Control Panel**: Simple interactive terminal management interface.

---

## 🚀 Usage

- Run `start_silent.vbs` to launch the background service.
- Run `command_center.bat` for the interactive control panel.
